# Treasure Hunt – Lost Cave

## Project Overview

**Treasure Hunt – Lost Cave** is a 3D adventure game developed using Unity and C#. The game takes players on an exciting journey through a mysterious cave environment, where they explore different levels, overcome obstacles, collect treasures, and progress toward the final treasure chamber.

The project demonstrates game development concepts such as player movement, collision detection, scene management, interactive environments, and game logic.

## Technologies Used

- **Game Engine:** Unity
- **Programming Language:** C#
- **Development Environment:** Unity Editor
- **Version Control:** Git
- **Repository Hosting:** GitHub
- **Platform:** Windows (development)

## Game Objectives

The main objectives of the game are:

1. Explore the mysterious cave environment.
2. Navigate through different levels.
3. Avoid obstacles and environmental hazards.
4. Discover and collect valuable treasures.
5. Progress through the cave to reach the final chamber.
6. Complete the adventure successfully.

## Game Levels

### Main Menu

### Instructions

### Level Selection

The final level, where players work toward reaching the hidden treasure.

The completion screen marking the end of the adventure.

## Main Game Components

The project organizes its C# scripts into the following modules:

- **GameManager:** Core game management.
- **Player:** Player-related functionality.
- **Camera:** Camera behavior.
- **Collectibles:** Collectible item functionality.
- **Obstacles:** Environmental obstacle logic.
- **Interactions:** Interactions with game objects.
- **LevelManagement:** Level and scene management.
- **Procedural:** Procedural game components.
- **UI:** User interface components.

## How to Run the Project

1. Install Unity Hub and a compatible Unity Editor version.
2. Clone or download this GitHub repository.
3. Open Unity Hub.
4. Select **Add Project** and choose the downloaded project folder.
5. Open the project using the compatible Unity Editor.
6. Open `Assets/Scenes/MainMenu.unity`.
7. Click the **Play** button in Unity to test the game.
